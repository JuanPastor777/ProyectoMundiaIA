# Decisiones del Proyecto

## React

Se eligió React porque permite desarrollar una interfaz moderna, organizada y fácil de mantener.

## FastAPI

Se utilizará FastAPI como backend debido a su buen rendimiento, facilidad para crear APIs REST y su integración con Python.

## Supabase

Se eligió Supabase porque facilita la administración de la base de datos, la autenticación y la conexión con PostgreSQL.

## PostgreSQL

Se utilizará PostgreSQL como motor de base de datos por su estabilidad, seguridad y buen manejo de relaciones entre tablas.

## OpenAI

El agente de IA utilizará la API de OpenAI para responder consultas relacionadas con el torneo y apoyar a los organizadores.

## GitHub

El proyecto será administrado mediante GitHub para llevar el control de versiones y facilitar el trabajo colaborativo del equipo.
